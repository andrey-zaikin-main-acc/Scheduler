# Production Planner MVP

Локальный однопользовательский MVP приложения планирования производства с хранением данных в SQLite.

## Цель

Прототип проверяет ключевую расчётную логику:

- расчёт потребности по трудоёмкости на 1000 шт.;
- обратное планирование от срока отгрузки;
- учёт маршрутов и производственных участков;
- частичную передачу партии между операциями;
- пересчёт всего плана при изменениях;
- выявление конфликтов;
- свободные слоты и предварительную проверку доступного тиража по маршруту;
- поиск возможных дат отгрузки без создания заказа;
- диаграмму Ганта по заказам и по участкам.

## Стек

- Python 3.12+
- Streamlit
- SQLite
- SQLAlchemy
- Plotly
- pytest

## Локальный запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app/main.py
```

## Актуальные seed-данные

Seed-данные загружаются из `app/db/seed_data.py` и соответствуют исходному Excel-файлу:
реальные производственные участки, 8 технологических потоков и минимальный набор заказов
на этих маршрутах.

Чтобы пересоздать локальную SQLite-базу и убрать прежние тестовые/demo-данные:

```bash
python -m app.db.seed_data --reset
```

Чтобы только дозагрузить/обновить актуальные seed-данные без удаления всей базы:

```bash
python -m app.db.seed_data
```

## Работа с заказами

В реестре заказов доступен предварительный блок «Проверка доступного тиража и слотов отгрузки». Он рассчитывает свободную мощность активного маршрута за выбранный период, показывает ограничивающий участок и может подобрать даты отгрузки для заданного тиража без создания заказа и без изменения сохранённого плана.
