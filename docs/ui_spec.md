# Спецификация интерфейса MVP

## Общие требования

- Приложение запускается локально.
- Авторизация не нужна.
- Данные сохраняются в SQLite.
- Пересчёт запускается автоматически после сохранения изменений и вручную кнопкой «Пересчитать план».

## Реестр заказов

Колонки:

- ID / номер заказа;
- клиент;
- продукция;
- тираж;
- срок отгрузки;
- маршрут;
- статус;
- рассчитанная дата запуска;
- признак конфликта.

Действия:

- создать заказ;
- редактировать заказ;
- отменить заказ;
- изменить статус;
- пересчитать план.

Клиент и продукция в MVP — текстовые поля.

## Форма заказа

Поля:

- номер заказа;
- клиент;
- продукция;
- тираж;
- срок отгрузки;
- маршрут;
- статус.

Валидация:

- тираж больше 0;
- срок отгрузки заполнен;
- маршрут выбран.

## Справочник участков

Поля:

- название;
- доступные часы в день;
- активность.

Валидация:

- доступные часы должны быть больше 0.

## Справочник маршрутов

Поля маршрута:

- название;
- описание;
- активность.

Поля операции маршрута:

- порядковый номер;
- участок;
- трудоёмкость на 1000 шт.;
- минимальная передаточная партия к следующей операции.

Валидация:

- маршрут должен иметь хотя бы одну операцию для планирования заказов;
- трудоёмкость операции должна быть больше 0.

## Производственный план

Показывает плановые операции и дневные размещения.

Фильтры:

- период;
- участок;
- заказ;
- статус.

## Диаграмма Ганта

Режимы:

1. По заказам — строки соответствуют заказам, полосы соответствуют операциям.
2. По участкам — строки соответствуют участкам, полосы соответствуют заказам/операциям.

В подсказке операции показываются:

- заказ;
- участок;
- операция маршрута;
- дата начала;
- дата окончания;
- плановые часы.

## Свободные слоты

Период выбирает пользователь. По умолчанию — ближайшие 30 дней.

Показывается:

- участок;
- дата;
- доступные часы;
- занятые часы;
- свободные часы.

Отдельно показывается примерный возможный тираж по маршрутам.

## Конфликты

Показывается:

- заказ;
- срок отгрузки;
- ограничивающий участок;
- требуемые часы;
- свободные часы;
- дефицит;
- мешающие заказы;
- причина.

## Результаты пересчёта

Показывается последний пересчёт:

- дата и время запуска;
- статус;
- краткая сводка;
- список изменений.

Полное версионирование плана в MVP не требуется.
